## Release invariants

Release work must not weaken architecture merely for convenience.

1. **No release-only authority shortcut.** Packaging and documentation do not bypass Task, Verification, Artifact, provenance, promotion, merge, or release gates.
2. **No hidden installer side effects.** Importing or invoking help for packaged commands must not initialize/migrate a project, load a model, acquire a resource lease, run an external tool, or mutate a repository.
3. **Attempt means one bounded attempt.** The installed attempt command exposes the existing single-attempt orchestrator and is not renamed or documented as an unlimited autonomous retry agent.
4. **Attempt preflight cannot initialize partial state.** Missing config/database, empty or stale database state, missing project binding, or active journal state must fail before the normal writer path rather than creating/migrating project state.
5. **Cockpit remains read-only.** The installed cockpit exposes exactly the bounded Phase-30 `snapshot` / `serve` surface.
6. **Version transition is explicit.** `0.1.0` is the deliberately selected first release version and must be proven on the exact immutable version/license candidate before tagging.
7. **Licensing is explicit.** Apache License 2.0 is the selected v0.1.0 distribution license; the canonical license text is stored at repository root as `LICENSE`.
8. **Tagging is downstream evidence, not verification.** A Git tag does not substitute for the exact-head test/review gates.

## Explicit non-goals for v0.1 release hardening

Release hardening does not add:

- automatic merge or release authority;
- a new unbounded retry controller;
- UI mutation workflows;
- remote/multi-user cockpit hosting;
- arbitrary Artifact-byte/media preview serving;
- arbitrary shell/filesystem/process access;
- checkpoint/model activation;
- live self-training/self-modification;
- implicit provenance signing or trust verification;
- automatic Dream memory promotion.

Any such capability requires a separately governed future design rather than being smuggled into packaging or release scripts.
