## Release invariants preserved

1. **No release-only authority shortcut.** Packaging/documentation do not bypass Task, Verification, Artifact, provenance, promotion, merge, or release gates.
2. **No hidden installer side effects.** Import/help for packaged commands does not initialize/migrate a project, load a model, acquire a resource lease, run an external tool, or mutate a repository.
3. **Attempt means one bounded attempt.** The installed attempt command exposes the single-attempt orchestrator and is not an unlimited retry agent.
4. **Attempt preflight cannot initialize partial state.** Missing config/database, invalid database state, missing project binding, or active journal state fails before the normal writer path.
5. **Cockpit remains read-only.** The installed cockpit exposes exactly the bounded Phase-30 `snapshot` / `serve` surface.
6. **Version transition was explicit.** `0.1.0` was deliberately selected and proven on the exact immutable final candidate before tagging.
7. **Licensing is explicit.** Apache License 2.0 is the v0.1.0 distribution license.
8. **Tagging is downstream evidence, not verification.** The tag was created only after exact-head test/review/merge proof.
